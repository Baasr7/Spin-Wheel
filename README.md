# Spin The Wheel - The Ultimate Decision & Elimination Tool

![Spin The Wheel Showcase]()

## The Story Behind The Wheel

Have you ever doomscrolled on YouTube Shorts or Instagram Reels and come across a series of content that's plain, but so engaging? I did. I noticed channels creating daily knock-off-style videos with a spinning wheel, garnering thousands of views by knocking out one entry at a time until one winner was left.

It was a great idea, and I desired my own series. The catch? The most used platform for this, Picker Wheel, has a strict copyright policy which doesn't allow the use of their wheel in monetized or public material. I required a tool which was not only useable but owned by me.

Therefore, I chose to develop it using Googl's Gemini 2.5 pro. That project is the culmination: a fully feature-rich, fully customizable spinning wheel constructed using normal web devs, open to use with no copyright, and designed with ❤️ for content creation in mind.

## Features

* **Customizable & Automatic:** Add entries on the fly. The wheel updates in real-time and automatically removes the winner, perfect for elimination-style content.
* **Immersive Experience:** Features a smooth, realistic spinning animation and a satisfying "tick" sound for each segment, making it engaging for viewers.
* **Clean & Focused Design:** A modern, focused UI with a custom theme that makes the wheel the star of the show.
* **Lightweight & Fast:** Built with pure HTML, CSS, and JavaScript for maximum performance and easy modification.

## How to Use

This project is built with standard, framework-free web technologies. To run it, you just need a modern web browser.

1.  **Clone or Download the Repository:**
    Get the files onto your local machine.

    ```bash
    git clone [https://github.com/your-username/spin-the-wheel.git](https://github.com/your-username/spin-the-wheel.git)
    ```

2.  **Organize Your Files:**
    Make sure the three main files are in the same directory:
    * `index.html` (The main structure)
    * `style.css` (All the styling rules)
    * `script.js` (The application logic)

3.  **Open in Your Browser:**
    Simply open the `index.html` file in your web browser (like Chrome, Firefox, or Edge). The app will run locally without needing a web server.

4.  **Start Creating!**
    * Scroll down to the "Enter Options" section to add your entries (one per line).
    * Click the "SPIN" button in the center of the wheel to start the animation.
    * Record your screen to create your video content.

## Project Journey

This project evolved from a basic concept into a full-featured tool for content creators. The journey involved implementing the core spinning logic on an HTML canvas, adding the crucial automatic winner-removal feature, integrating `Tone.js` for satisfying sound effects, and completely overhauling the UI for a professional, focused experience. The result is a stable and reliable tool ready for its YouTube debut.
